
Örnek Uygulamalar
================

Genel Bakış
-----------

Bu bölümde SmartCore STM32L412 geliştirme
kartı için hazırlanan örnek uygulamalar
yer alacaktır.

Örnekler STM32CubeIDE geliştirme ortamı
ve STM32 HAL kütüphanesi temel alınarak
hazırlanacaktır.

Örnek Projeler
--------------

1. GPIO LED Kontrolü
~~~~~~~~~~~~~~~~~~~~

Kart üzerindeki kullanıcı LED'inin
GPIO çıkışı üzerinden kontrol edilmesi.

2. Buton Okuma
~~~~~~~~~~~~~~

Kullanıcı butonunun GPIO girişi üzerinden
okunması ve durumunun değerlendirilmesi.

3. UART Haberleşmesi
~~~~~~~~~~~~~~~~~~~~

UART arayüzü üzerinden veri gönderme
ve alma uygulaması.

4. I2C Haberleşmesi
~~~~~~~~~~~~~~~~~~~

I2C arayüzü üzerinden çevresel bir
cihazla haberleşme uygulaması.

5. SPI Haberleşmesi
~~~~~~~~~~~~~~~~~~~

SPI arayüzü üzerinden çevresel bir
cihazla veri alışverişi uygulaması.

Proje Dosyaları
---------------

STM32CubeIDE örnek projeleri hazırlandıkça
GitHub deposundaki ``examples`` klasörüne
eklenecektir.

GitHub Deposu
-------------

https://github.com/fatihbasaris/smartcore-stm32l412

Önemli Notlar
-------------

Örnek uygulamalardaki GPIO ve çevresel
birim pinleri kartın gerçek devre şemasına
göre yapılandırılacaktır.

Örnek projelerin donanım üzerinde
doğrulanma durumları ayrıca belirtilecektir.
